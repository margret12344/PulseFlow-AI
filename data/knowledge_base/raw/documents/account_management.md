# Account Management

## Purpose

This synthetic document provides general procedures for handling
user account and authentication issues in a hospital IT environment.

## Common Issues

- Unable to sign in.
- Account temporarily locked.
- Password reset requests.
- Missing system permissions.
- New employee account requests.

## Password Reset Procedure

1. Verify the user's identity through an approved process.
2. Confirm that the request concerns password recovery.
3. Direct the user to the approved password reset procedure.
4. Never request or store the user's current password.
5. Escalate failed reset attempts to the Identity Management Team.

## Account Lockout

1. Record the displayed error message.
2. Determine whether one or multiple accounts are affected.
3. Check whether repeated failed login attempts occurred.
4. Escalate suspected unauthorized access to the Security Team.
5. Never bypass account security controls.

## Access and Permission Requests

1. Identify the requested application or system.
2. Record the user's department and job role.
3. Document the specific access required.
4. Obtain authorization before granting access.
5. Route approved requests to the responsible team.

## Escalation Conditions

- Account remains locked after approved recovery steps.
- Unauthorized access is suspected.
- Multiple users experience authentication failures.
- Required permissions cannot be verified.
- Administrative privileges are required.

## Required Ticket Information

- User identifier.
- Affected application.
- Error message.
- Time of occurrence.
- Requested access or action.
- Authorization status.

## Security Notes

Never request passwords or authentication codes.
Never share credentials through support tickets.
Never grant permissions without authorization.

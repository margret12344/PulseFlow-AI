# Software Troubleshooting

## Purpose

This synthetic document provides initial procedures for
resolving common software and application issues.

## Common Symptoms

- Application fails to launch.
- Application freezes or crashes.
- Unexpected error messages appear.
- Application performance is slow.
- Software update fails.

## Initial Troubleshooting

1. Identify the affected application and its version.
2. Record the exact error message.
3. Determine whether the issue affects one or multiple users.
4. Check whether the application is available to other users.
5. Restart the application if permitted by the applicable procedure.
6. Check for known service interruptions.
7. Document all troubleshooting actions.

## Application Access Issues

1. Verify that the user can access the required system.
2. Check whether the issue is related to authentication.
3. Confirm whether the user has the required permissions.
4. Route account-related issues to the Identity Management Team.

## Escalation Conditions

- Application remains unavailable.
- Multiple users report the same failure.
- Application crashes repeatedly.
- Data integrity problems are suspected.
- An update causes unexpected system behavior.

## Required Ticket Information

- Application name and version.
- Operating system.
- User identifier.
- Error message or error code.
- Time of occurrence.
- Number of affected users.
- Steps already attempted.

## Security Notes

Do not install unauthorized software.
Do not disable security controls to resolve application issues.
Do not share confidential application data in support tickets.
